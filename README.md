# physboard-web
唐长老超级物理白板是一款面向物理课堂的白板软件，支持全屏透明、始终置顶，可直接在课件、视频或网页上批注。  核心功能包括：笔、像素橡皮、形状库（内置大量高中物理相关图形和动画，可连续选形、分类滑动、面板锁定）；文字排版、MathJax 公式与内置 LaTeX 公式编辑器；函数绘图、文字生成电路图、JSXGraph 图形；图形动画、参数调节、播放/暂停/重置。  支持多页白板，每页可独立平移和缩放；可导入图片、视频、PDF/PPT，PDF/PPT 按页铺为背景。可导出当前页、全部页或指定页图片，录制视频，保存工程文件。  另含 8 个小程序：本地时间、倒计时、秒表、点名器、随机数、骰子、拾音频谱、物理公式球，支持自由缩放、字号跟随。适合课堂演示、习题讲解、学术研究与微课录制。
